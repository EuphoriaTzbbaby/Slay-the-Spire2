# 游戏主代码：SpireCompanion

C# / .NET 9 单人 Mod 的正式开发目录。已有状态读取、文字/语音聊天、局外自动操作和 CombatSolver 接管/停止桥接。战斗执行交给求解器；角色策略由对应同学继续优化。

| 目录 | 用途 |
| --- | --- |
| SpireCompanion | 游戏 Mod、状态读取、界面和原生操作。 |
| SpireCompanion.Core | 不依赖游戏的核心源码；主 Mod 直接编入，检查工程单独引用。 |
| SpireCompanion.Checks | 不启动游戏的控制、聊天、语音与指令检查。 |

## 单次战斗外指令（2026-11-04）

文字和最终语音转写共用入口。无需打开“局外自动操作”：在当前可操作界面明确下达指令，AI 从真实选项中决策并提交点击，处理本次选择后停下。

| 玩家说法 | 行为 |
| --- | --- |
| “帮我选一张适合当前卡组的牌” | 在当前奖励选项中决定并选择一张。 |
| “这里休息” | 当前休息点有可用休息选项时提交选择。 |
| “买这件商品” / “帮我买指定名称的商品” | 根据当前商店选项和指令选商品；目标含糊或不可买时应说明而不乱点。 |
| “帮我选一条稳一点的路线” | 当前地图上选择一个可达节点。 |
| “确认选择” / “跳过奖励” | 只在当前界面确实提供对应选项时执行。 |
| “哪张更好” / “先别买” / “只分析” | 只给建议，不授予本轮操作工具。 |

当前支持奖励卡、奖励结算、休息点、商店、选牌、事件、地图、遗物与宝箱。一条指令只处理当前屏幕的一次选择；选择锻造、打开商品或事件跳到新的决策界面后，需要根据新界面再下指令，不会继续跑后面的房间。选牌可提供界面要求的多个不同候选，并尝试完成确认；原有选择与本轮目标冲突时停止并提示。

“暂停所有本模块动作”、聊天“取消”及语音“暂停”会取消尚未执行的操作。已送达游戏的点击不能靠取消回复撤销；回执会保留，补充说话不会重放原操作。普通聊天仍会挂起已开启的连续自动；单次指令不会把自动开关重新打开。

游戏里显示真实操作回执；“已提交”表示点击已交给游戏，不保证动画、购买或奖励已经结算。模型服务不支持工具时明确显示未点击并退回文字建议。执行前重新检查状态指纹、可用选项、单人/战斗状态及请求是否已取消，界面变化后丢弃旧指令。

内部聊天工具为 `choose_room_option`，参数是当前快照的 `id`，多选另给 `ids` 且首项与 `id` 一致；仅明确指令时提供。工具每条消息只允许一次执行，不能使用任意桌面坐标、调用操作系统或在战斗中出牌。Python 语音协议不变，语音服务只提交最终文字。

自动检查覆盖意图入口、只读聊天、选项/过期状态、重复调用、取消、回执保存和不支持工具的服务。**新指令入口的真实模型选择与游戏点击尚待实机验收**，不以模拟模型通过代替。验证时进入可用的奖励或休息点，先问建议，再明确要求执行，确认只发生本次操作。

## 构建、安装与检查

从仓库根目录执行：

```bash
python3 scripts/game_dev.py check
python3 scripts/game_dev.py build
python3 scripts/game_dev.py install
```

安装脚本先备份旧 Mod，再复制已构建文件；不修改存档或其他 Mod。开发机准备了语音环境时还会生成本机启动配置，macOS 构建独立语音授权应用。C# 更新必须重启游戏，没有热重载；F9 显示/隐藏窗口，QQ 或麦克风按钮控制语音，玩家日常不必在终端启动 Python。

macOS 自动定位标准 Steam 安装。Windows 指定游戏数据目录，或用 `local.props.example` 配置本机路径：

```powershell
python scripts/game_dev.py build --game-data "C:/Program Files (x86)/Steam/steamapps/common/Slay the Spire 2/data_sts2_windows_x86_64"
python scripts/game_dev.py install --mods-dir "实际 mods 目录"
```

本机路径、模型、游戏程序集和构建产物不提交 Git。Windows 安装见 [Windows 加载 Mod 指南](../../docs/Windows-加载Mod指南.md)，语音与玩家运行时交付见 [voice/README.md](../../voice/README.md)。

`python3 scripts/game_smoke.py` 可做 macOS 独立离线加载检查，不使用真实跑局或 Steam 存档；它不证明真实操作效果。推送后还要核对该提交的 GitHub Actions，不能只确认 push 成功。

## 模型与状态

在“设置”填写 Chat Completions 服务地址、模型名与 API Key；“聊天”可发送消息或分析局面，支持取消、历史和回复风格。API Key 使用 [跨平台加密档案](../../docs/APIKey本地加密存储与账户档案.md)，系统安全存储只用于自动解锁；不写入源码仓库。

快照包含当前界面选项、角色、卡组、生命、金币及可读战斗信息，聊天和指令共享本局计划。图鉴与实时状态工具仍是只读。调试导出写入游戏用户目录，不执行动作，也不包含隐藏抽牌顺序或密钥。

开发规划与历史证据见 [规划](../../docs/单人版游戏模块开发规划.md)、[进度](../../docs/单人版游戏模块开发进度.md)及 [文字聊天记录](../../docs/游戏模块文字聊天开发记录.md)。
