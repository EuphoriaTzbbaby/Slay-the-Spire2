# 游戏端

语言：C#，.NET 9，复用游戏现有 Godot 接口。负责游戏状态、角色权限、双开组队、决策、战斗执行、交接、暂停和日志。

| 目录 | 用途 |
| --- | --- |
| spire-buddy | 独立上游子模块，聊天和自动操作基础。 |
| STS2-Agent | 独立上游子模块，双开、联机和 API 基础。 |
| CombatSolver | 独立上游子模块，战斗模拟、搜索与执行基础。 |
| legacy | 后续 C# 游戏主代码开发目录，旧 Python 原型已清理。 |

正式游戏代码在 legacy/ 内开发，已建立 SpireCompanion 主工程和独立控制检查；当前是默认暂停的手动验证版本，尚未接入完整自动托管。不要同时启动多个控制器执行游戏动作，多人适配仍待实现。

每个子模块保留原 Git 历史、远端和许可证。可从此处阅读源码；需要修改时，先按模块内说明开发，并将提交发布到团队 fork 后再更新主仓库引用。新克隆默认处于锁定提交，开发前在子模块中创建任务分支。

接口修改需同步更新 ../protocol/ 和对应 API 文档。根目录脚本检查目录与协议示例；各上游 C# 项目的构建方法见各自 README。主工程构建、检查与安装方法见 [legacy/README.md](legacy/README.md)。

单人阶段的具体开发顺序与任务拆解见 [单人版游戏模块开发规划](../docs/单人版游戏模块开发规划.md)。

任务完成情况见 [单人版游戏模块开发进度](../docs/单人版游戏模块开发进度.md)，完成标 ✓，未完成或未验证标 ✗。
