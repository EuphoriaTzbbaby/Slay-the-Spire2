# 语音服务

Python 独立进程，优先 Windows，后续适配 macOS。当前仅建立开发入口，尚无运行中的语音服务。

职责：麦克风、默认唤醒词“搭子”、中文识别、固定口令、语音合成、播报队列、插播、取消和打断。支持调整音量、语速和已安装音色。

语音端不执行游戏动作；向 C# 发送文本和控制请求，接收播报内容。优先免费本地模型，选型和设备效果待验证。

- 完整需求与接口：[语音模块 API](../docs/语音模块-开发功能与API.md)。
- 消息约定：[protocol](../protocol/README.md)。

后续源码放入 src/，测试放入 tests/，依赖放入独立 pyproject.toml。不要复用 game/legacy 的 Python 包名或环境配置。模型、录音、密钥和个人设备设置不提交。
