# 协作：两个队友分别优化不同角色时怎么合并

日期：2026-10-29  
适用：多人同时改本仓库，尤其是"一个人优化铁甲、一个人优化静默/机器人"。

---

## 1. 总原则

- `main` 永远可发布；任何人不在 `main` 上直接改；
- 一个角色一个分支、一个 PR，PR 只做一件事；
- 共享文件（`ChatClient.cs`、`CompanionPanel.cs`、`GameReader.cs`）改动越少越好，改之前先在群里说一声；
- 合并前必须：`git pull --rebase origin main` + 本地 `game_dev.py check` 通过 + CI 通过。

---

## 2. 代码结构：一人一个文件

角色建议已经拆成互不重叠的文件：

```
game/legacy/SpireCompanion.Core/
├── CharacterProfiles.cs      # 接口 + 注册表（共享，改动需协调）
├── CharacterIronclad.cs      # 铁甲：A 队友负责
├── CharacterSilent.cs        # 静默：B 队友负责
└── CharacterDefect.cs        # 故障：C 队友负责
```

每个人只改自己的 `Character<角色>.cs`，**不会产生同一文件的冲突**。  
如果两人都要改注册表/提示词/决策链路，先合并一个人，另一个人 rebase 后再改。

---

## 3. 分支命名

```
feat/ironclad-draft
feat/silent-draft
feat/defect-draft
fix/ironclad-combat
```

不要长期保留 `dev-张三` 这种大分支；小步提交、尽快 PR。

---

## 4. 标准流程

```bash
# 1. 同步
git switch main
git pull --ff-only origin main

# 2. 开分支
git switch -c feat/silent-draft

# 3. 只改自己的角色文件 + 对应测试
#    game/legacy/SpireCompanion.Core/CharacterSilent.cs

# 4. 本地验证
python3 scripts/game_dev.py check

# 5. 提交并推送
git add -A
git commit -m "feat(silent): 调整中毒流选牌优先级"
git push -u origin feat/silent-draft

# 6. 开 PR → 等 CI 绿 → 合并
```

合并前如果 main 已前进：

```bash
git fetch origin
git rebase origin/main
# 解决冲突后
git push --force-with-lease
```

---

## 5. 冲突怎么处理

| 冲突文件 | 处理 |
| --- | --- |
| `Character<角色>.cs` | 理论上不该冲突；若冲突，保留两人最新内容并跑检查 |
| `CharacterProfiles.cs` | 通常只是新增一行注册；两边都保留 |
| `ChatClient.cs` / `CompanionPanel.cs` | 先合并一个人的 PR，另一个 rebase 后手动改；不要直接覆盖 |
| 文档 | 保留双方内容，按章节合并 |

冲突解决后必须重新跑：

```bash
python3 scripts/game_dev.py check
```

---

## 6. 测试与验收

- 通用检查：`python3 scripts/game_dev.py check`（当前 46 项）；
- 角色相关：用对应角色进一局，看奖励/商店/战斗建议是否带该角色机制；
- 非铁甲自动战斗：确认 CombatSolver 是否接管，日志 `solver_auto_*`；
- 不要把 `local.props`、`dist/`、日志、存档提交进仓库（已在 `.gitignore`）。

---

## 7. 发布

`main` 合并后由维护者执行：

```bash
python3 scripts/package_release.py
python3 scripts/publish_release.py
```

队友更新：

- 有仓库：`scripts\update_from_repo.bat`；
- 只玩：固定链接下载 zip → `install.bat`。

---

## 8. 如果队友用自己的 fork

```bash
git remote add upstream https://github.com/EuphoriaTzbbaby/Slay-the-Spire2.git
git fetch upstream
git rebase upstream/main
git push origin feat/silent-draft
```

然后在 GitHub 上从 fork 向本仓库开 PR。
