## 快速排错

| 现象 | 优先检查 |
|---|---|
| capture 没输出 | mod 是否 Enabled；`mods` 路径；BaseLib `.pck/.json`；5000 端口 |
| `Address already in use` | 是否同时开了 `make serve` 或上游 `server.py`；用 `lsof` 查 |
| `lsof` 显示 `ControlCe` 占用 5000 | macOS AirPlay Receiver；系统设置 → 通用 → 隔空投送与接力 → 关闭「隔空播放接收器」 |
| inspect 最后一条是 Loot | 用 S3-1 列表找 `kind=combat` 的索引 |
| 结论是 `degraded` | 预期；记录缺字段，继续发报告 |
| macOS 不加载 mod | 先用 Windows 验证；或确认当前 StS2 版本支持 |
| 游戏更新后失效 | 锁版本；记录 BaseLib/mod commit；必要时回滚 |
