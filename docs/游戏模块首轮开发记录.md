## 本轮实现

- game/legacy/SpireCompanion：独立 Mod 入口、F9 开发面板，读取本地角色、血量、金币、场景、手牌和战斗阶段。
- game/legacy/SpireCompanion.Core：默认暂停、控制版本失效、快照校验、同状态去重、重入拦截和异常后禁止盲目重试。
- 手动结束回合：执行前复核阶段、结算队列、手牌模式和覆盖界面，通过游戏 PlayerCmd.EndTurn 提交一次。
- 不支持多人和非铁甲战士动作。检测到 Buddy、STS2-Agent 或 CombatSolver 程序集时，本阶段禁用动作，避免多个控制器争用。
- scripts/game_dev.py：独立的构建、检查和安装入口。安装已有模块前备份，不修改其他 Mod 或存档。
- CI 配置新增不依赖游戏的控制检查；尚未在 GitHub 运行此版本。

本阶段的“恢复”只启用手动动作，不等于启动自动托管；状态变化后保守暂停。自动识别所有外部 Mod 的控制权尚未实现，当前只检测明确列出的程序集。
