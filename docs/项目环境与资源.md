# 项目环境与资源

## 已确认的基础设施

用户于 2026-10-27 明确说明：

- 已有云服务器。
- 已有云服务器上的数据库，类型为 MySQL。
- 后续账户、API Key 存储和跨设备配置方案需要考虑这些现有资源，不应默认没有后端或数据库。

数据库版本、服务器系统、现有后端、域名、HTTPS、登录方式及部署权限尚未确认。此文档只记录资源存在，不表示已建立连接或获得部署凭据。

不要在项目文档、Git 或聊天中保存数据库密码、模型密钥和服务器登录密钥；实际连接信息通过部署环境提供。

## API Key 存储的当前安排

用户已选择第一阶段采用跨平台本地加密文件、本地账户档案和解锁密码；允许系统安全存储缓存文件解密凭据以便自动解锁。每位玩家使用自己的 API Key。云端登录与 MySQL 同步留到后续，不在本轮连接服务器。旧密钥保留并提供显式导入入口。

实现说明见 [API Key 本地加密存储与账户档案](APIKey本地加密存储与账户档案.md)。

后续可选扩展：

| 方案 | 主要特点 |
| --- | --- |
| 云端保存与模型转发 | 客户端通过认证访问后端；后端加密保存密钥并调用模型，数据库不向客户端开放。需要明确账户隔离、访问权限和请求额度。 |
| 云端保存，客户端取回后直连模型 | 可跨设备同步，但需要明确授权读取密钥及本地缓存规则，密钥会返回客户端。 |
| 跨平台本地加密文件 | 不要求连接服务器；加密口令或解密密钥的管理需要另行明确，不能把加密密钥硬编码到客户端。 |

本地方案已实施核心代码；云端扩展仍需确认，不将候选设计写成已部署能力。优先复用现有后端；没有后端时再建立轻量 API 服务。游戏端经 HTTPS API 访问后端，不直接连接云数据库。

参考：[OWASP 数据库安全](https://cheatsheetseries.owasp.org/cheatsheets/Database_Security_Cheat_Sheet.html)、[OWASP 密钥管理](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html)。
