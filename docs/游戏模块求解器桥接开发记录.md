## 首次独立加载发现的问题

独立副本、关闭 Steam、使用新测试账号加载成功，但 SystemFont 在 headless 环境中没有可用字体提供者，导致字体错误。已改用游戏 FontManager 的中文字体；新的加载测试需检查面板就绪日志和字体相关错误。

测试结束后清理副本和本次新建的离线账号，仅保留 .local/smoke 下日志，不使用或覆盖玩家存档。无头退出时可能有游戏资源释放警告，不能将其自动等同于本模块逻辑失败，也不能掩盖初始化或读取错误。

## 独立控制验证

本轮 11 项检查通过，包含原有暂停、防重复检查，以及：

- 不兼容控制器缺少停止能力时拒绝接入。
- 接管调用未实际改变自动状态时报告失败。
- 停止后确认禁用、自动关闭、搜索和部署结束，且不持久化改变用户配置。
- 部署仍未停止时，不误报暂停成功。
- 状态快照可以序列化往返，能量和敌人变化会使状态指纹失效。

求解器相关检查使用模拟控制器，不等于实际求解器战斗测试。

## 仍需验证

- 用户实际求解器版本是否提供兼容反射入口。
- 同时加载本模块与 CombatSolver 后，显示状态、交接和停止是否正确。
- 结束战斗、暂停期间和再次接管时，是否正确管理执行权。
- 可见面板字体、布局和实际战斗中的状态与操作。

## 后续状态与生命周期补充

- 战斗结束后停止本模块接管的求解器，不把“接管本场”延续到下一场。
- 游戏退出时发起停止；缺少兼容控制器时明确显示版本不兼容，不影响基本只读面板。
- 状态快照新增能量、格挡、带序号与费用的手牌、敌人生命与格挡、牌组、遗物、药水槽位；不包含隐藏抽牌顺序。
- 卡组中非手牌的动态费用明确标为未计算，不用当前战斗费用误导局外策略。
- 新增调试导出按钮，将 fresh 快照写入 user://spire-companion/captures，并在日志中报告位置，不包含 API 密钥。
- 修复快照指纹计算属性的序列化边界，避免递归；独立检查覆盖往返和状态变化。

独立加载检查通过只说明入口、中文字体资源和主菜单状态可用，不代表可见画面、战斗状态数值或求解器联合运行已验收。
