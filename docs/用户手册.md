# 尖塔 AI 陪玩 · 用户手册

适用版本：开发版 `0.1.0`（2026-10-28）  
适用对象：拿到本仓库、想在自己电脑上安装试用的队友与测试者。  
开发细节见 [单人版游戏模块开发进度](单人版游戏模块开发进度.md)；本手册只讲**怎么用**。

---

## 1. 它是什么

一个装在《杀戮尖塔 2》里的陪玩 Mod：

- **聊天**：随时问它当前局面怎么打，它会读你的真实状态（血量、手牌、金币、遗物、牌组、当前界面）再回答，不是凭空聊天。
- **主动说话**：进战斗时会说一句，血量危险时提醒你一次。
- **局外自动操作**：奖励结算、休息点、商店、选牌、事件、地图、遗物、宝箱——你开一个开关，它自己选、自己点。
- **战斗交给 CombatSolver**：战斗不归它管，它只负责把战斗交给求解器、看求解器状态、暂停。

它**不会**做这些：不会改你的存档、不会碰别人的 Mod、不会在没有你同意时动战斗。

## 2. 安装前准备

| 需要什么 | 说明 |
| --- | --- |
| 《杀戮尖塔 2》 | 单人模式；本 Mod 只支持单人 |
| **RitsuLib** | 创意工坊订阅；CombatSolver 也依赖它 |
| **CombatSolver**（自动战斗必需） | 创意工坊订阅或按源码构建；**不装就只能聊天和局外自动，战斗不会自动进行** |
| .NET 9 SDK（只有自己构建才需要） | 直接拿 DLL 的人不需要 |

macOS 的 mods 目录在游戏包内：

```
~/Library/Application Support/Steam/steamapps/common/Slay the Spire 2/SlayTheSpire2.app/Contents/MacOS/mods/
```

Windows 在游戏根目录：

```
...\steamapps\common\Slay the Spire 2\mods\
```

## 3. 安装

### 方式 A：脚本安装（推荐，仓库内）

macOS：

```bash
python3 scripts/game_dev.py build
python3 scripts/game_dev.py install
```

Windows（必须指定 mods 目录）：

```bash
python scripts/game_dev.py build --game-data "C:/Program Files (x86)/Steam/steamapps/common/Slay the Spire 2/data_sts2_windows_x86_64" --mods-dir "C:/Program Files (x86)/Steam/steamapps/common/Slay the Spire 2/mods"
python scripts/game_dev.py install --mods-dir "C:/Program Files (x86)/Steam/steamapps/common/Slay the Spire 2/mods"
```

安装脚本只写 `mods/SpireCompanion/` 一处，覆盖前会把旧版本备份到仓库 `.local/mod-backups/`，**不碰存档和别的 Mod**。

### 方式 B：一键安装包（Windows，推荐给队友）

1. 拿到 `SpireCompanion-win64.zip`，解压；
2. 双击 `install.bat`；
3. 按提示确认游戏目录；
4. 脚本会复制 Mod，并检查 `CombatSolver` / `RitsuLib`，缺了会给提示和搜索关键词；
5. 启动游戏，确认 Mod 已启用。

> 自动战斗仍然需要自己订阅 `CombatSolver` 和 `RitsuLib`（Steam 创意工坊），安装脚本不能代替订阅。

### 方式 C：手动复制

在 mods 目录下新建 `SpireCompanion` 文件夹，放入三个文件：

```
SpireCompanion.dll
SpireCompanion.json
LICENSE
```

### 更新

1. **完全退出游戏**（不是回主菜单，是退出进程）；
2. 重新 build + install；
3. 再启动游戏。

本 Mod 没有热重载，更新后不重启不会生效。

### 确认加载成功

游戏日志出现这三行，就说明加载了：

```
Found mod manifest file .../mods/SpireCompanion/SpireCompanion.json
Loading assembly DLL .../SpireCompanion.dll
[SpireCompanion] 初始化：只读建议模式，F9 显示/隐藏窗口。
```

日志位置：

- macOS：`~/Library/Application Support/SlayTheSpire2/logs/godot.log`
- Windows：`%APPDATA%\SlayTheSpire2\logs\godot.log`

> 日志里出现 `does not declare min game version` 是正常的，不影响使用。

## 4. 第一次使用

1. 启动游戏，确认 Mod 列表里 **尖塔 AI 陪玩（开发版）** 已启用；
2. 进任意一局（主菜单也行），按 **F9** 或点左上角 **「AI 搭子」** 打开窗口；
3. 打开 **设置** 页，填：
   - **API 地址**：默认 `https://api.deepseek.com`；
   - **模型名称**：默认 `deepseek-flash`（会思考的模型也行，决策请求会自动关闭思考）；
   - **API Key**：填自己的密钥，勾选「记住 API Key」；
   - 点 **保存设置**；
   - 点 **测试连接**，看到"连接及模型调用成功"即可。
4. 回到 **聊天** 页，发一句"你好"试试。

### 关于账户档案

- 设置页顶部是 **账户档案**：可以建多个档案，配置和密钥相互独立；
- 密钥用本机加密档案保存，系统钥匙串只存解锁凭据；
- Key **不会**写进游戏设置、日志或 Git；
- 换电脑要重新填 Key。

## 5. 界面说明

窗口三个页签：**聊天 / 设置 / 游戏状态**。标题栏右侧显示：

- `自动：开` / `自动：关` / `自动：暂停`
- `求解器接管` / `只读建议`

### 5.1 聊天页

| 控件 | 作用 |
| --- | --- |
| 输入框 + **发送**（回车也行） | 提问，会带上当前局面 |
| **分析当前局面** | 不用打字，直接让它分析 |
| **取消回复** | 停掉正在进行的请求；同时会**暂停自动** |
| **清空** | 清空本次会话记录 |

- 回复分三档风格：**安静 / 普通 / 话多**，在设置里切换，**立即生效**；
- 它主动说的话，气泡前缀是 **「搭子」**；自动操作记录的前缀是 **「自动」**。

### 5.2 设置页

- **账户档案**：新建 / 解锁 / 切换 / 删除；
- **API 地址、模型名称、API Key**；
- **回复风格**：安静 / 普通 / 话多；
- **测试连接**：只发一次最小请求，不读游戏状态；
- **保存设置**：写入非秘密配置和加密密钥。

### 5.3 游戏状态页

从上到下四块：

1. **可以执行**：列出当前界面能点的选项，点一下执行；自动模式也在这一块显示"自动决策中…"和最近一次决策。
2. **当前局面**：角色、血量、金币、能量、手牌、敌人、牌组/遗物/药水数量、求解器状态。
3. **托管与求解器**：
   - **局外自动操作：开/关**：奖励、休息点、商店、选牌、事件、地图、遗物、宝箱自动处理；
   - **自动接管战斗：开/关**：每场战斗自动交给 CombatSolver；
   - **交给 CombatSolver 打本场战斗**：只接管当前这一场；
   - **暂停所有本模块动作**：立即停自动、停求解器；也可以**双击 W** 依次切换「关 → 开 → 暂停 → 恢复」（聊天输入框里不会触发）；
   - **恢复自动执行**：讨论打断后，用它继续。
4. **调试**：**导出当前状态**（排查问题用，导出路径会显示出来）。

## 6. 自动模式怎么工作

开启 **局外自动操作** 后，它在这些界面各做**一次**决策：

| 界面 | 它做什么 |
| --- | --- |
| 战斗奖励结算 | 依次领金币 → 药水 → 遗物 → 卡牌奖励（自动三选一）→ 离开 |
| 休息点 | 休息或锻造（自动选牌升级） |
| 商店 | 买一件或删一张牌；**买之前会预告并等 1.8 秒**，让你看清 |
| 卡牌奖励 | 选一张或跳过 |
| 选牌界面 | 选中并自动确认（多选界面会继续选，见限制） |
| 事件 | 点选项；多段对话会刷新继续 |
| 地图 | 选一个可达节点 |
| 遗物选择 | 选一个或跳过 |
| 宝箱 | 打开 → 拿遗物 → 离开（空箱子直接离开） |

规则与边界：

- **同一界面状态只操作一次**，避免死循环；
- 决策带 30 字理由，执行后聊天里会出现"自动：我选了「X」，理由…"；
- 模型回复不合法会自动重试一次；超时/失败会在聊天里说明并停止自动；
- 战斗期间自动让路给求解器，打完自动恢复；
- **你发消息或点取消，自动立即暂停**，点「恢复自动执行」才继续。

---

## 7. 战斗与 CombatSolver

- 战斗执行**只走 CombatSolver**，本 Mod 不自己出牌；
- 求解器没装时，「托管与求解器」里的相关按钮是灰的，这是正常的；
- 打开 **自动接管战斗** 后，每场战斗开始自动交给求解器，打完自动退出；
- **暂停所有本模块动作**会同时停掉自动和求解器后续动作。

## 8. 语音（尚未接入）

当前只支持**文字**输入输出。语音的规划是：

```
语音 → 识别成文字 → 模型 → 文字 → （以后）TTS 念出来
```

也就是说语音只换输入/输出两端，中间始终是文字；语音模块交付前，文字入口不受影响。接口细节见[语音模块接口与参数分析](语音模块-接口与参数分析.md)。

## 8.4 AI 可以主动查资料和实时状态

聊天时 AI 可以调用只读工具，而不是只靠上下文：

| 工具 | 能查什么 |
| --- | --- |
| `lookup_card` | 任意卡牌的费用与效果 |
| `lookup_relic` | 任意遗物效果 |
| `lookup_potion` | 任意药水效果 |
| `query_state` | 实时状态：`screen`（当前界面）、`hand`、`deck`、`relics`、`potions`、`enemies`（含下回合意图）、`run`（含进阶/楼层）、`map` |

查到的结果会回传给模型，再据此回答；查不到会说没有查到，不会硬编。

服务不支持工具调用时，自动退回"只读快照"模式，聊天仍然可用。

### 本局计划会保存

你说过的目标/规则会写入 `user://spire-companion/run-plan.json`，重启游戏后仍在；进入新楼层会请 AI 用一句话复盘并更新计划。

## 8.5 语音输入（阶段 2：语音 → 文字回复）

当前支持"语音输入、文字回答"，语音输出（TTS）还没接。

1. 游戏状态页打开 **「语音输入：开」**；
2. Mod 会把端口和会话令牌写到：

```text
~/Library/Application Support/SlayTheSpire2/spire-companion/voice-session.json
```

3. 启动语音服务（开发阶段用 mock）：

```bash
python3 voice/mock_voice_server.py
```

4. 在 mock 的终端里输入一句话回车，游戏聊天里就会出现"你：…"并得到文字回答；
5. 固定口令直接执行：
   - 暂停 / 等一下 → 暂停自动
   - 恢复 / 继续 → 恢复自动
   - 到你了 / 你来打 → 当前战斗交给求解器

真实语音（麦克风、唤醒「搭子」、ASR）由语音组实现，协议相同。

## 9. 隐私与费用

- 只有**当前局面摘要**（以及你的问题）会发给模型服务商；
- API Key 加密保存在本机，不进设置文件、不进日志；
- 决策请求会关闭模型的"思考"以省 token；
- 每次自动决策、主动发言都会产生一次模型调用，按你的服务商计费；嫌吵或想省钱可切「安静」并关掉自动。

## 10. 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 按 F9 没窗口 | Mod 没加载 | 完全退出游戏，确认 `mods/SpireCompanion/` 三个文件，确认 Mod 已启用，看日志第一条 |
| 窗口在但内容空白 | 状态读取失败 | 日志搜 `[SpireCompanion] read_state` |
| 发消息没回复 | Key/模型/网络/余额 | 先在设置里点「测试连接」；再看日志 `model request failed` |
| 回复只有一句话/很奇怪 | 模型或档位 | 切「普通/话多」再试；安静档本来就很短 |
| 自动模式不动 | 被暂停/没开/求解器接管中 | 看标题是「自动：开」还是「自动：暂停」；点「恢复自动执行」 |
| 自动模式在某个界面停住 | 该界面不支持或模型失败 | 看聊天里的原因；日志搜 `auto_` |
| 「交给 CombatSolver」是灰的 | 没装求解器或不在战斗 | 正常现象；装 CombatSolver + RitsuLib |
| 求解器不接管 | 缺 RitsuLib / 版本不匹配 / 非玩家回合 | 看求解器自己的提示与日志 |
| 切出去后游戏没声音 | 游戏自带「后台静音」 | 游戏设置 → 音频 → 关掉 Mute in Background |
| 卡在"移除两张牌" | 多选牌支持不完整（已知限制） | 手动点第二张并确认 |
| 游戏崩溃 | 先用日志确认是不是本 Mod | 关游戏，删 `mods/SpireCompanion/` 回退，把日志发我们 |

## 12. 已知限制

- **运营策略偏弱**：会在单个界面做局部选择，没有整局资源规划（路线/商店预算/篝火阈值等，在待办里）；
- **多选牌**（一次移除两张）偶尔只选一张就停，需要手动补；
- **语音未接入**；
- **Windows 未实测**：安装路径和脚本已支持，但没有实机验证记录；
- **只支持单人**，双排不在本 Mod 范围；
- 自动模式依赖模型响应，网络慢时会等待（单次决策最多 30 秒）。
